先に押さえること：ディレイへの割り込みと、ガード後の反撃は別

キムの214＋P（三連撃）→9＋K→ディレイ2＋Kは、相手を画面端に追い込んで繰り返し使われる重要な連係。ディレイ2Kへの割り込みと、ディレイをかけずに出し切った2Kをガードした後の確定反撃は、狙う時点も使える技も違う。

9K後に隙ができる：割り込みを狙う

ディレイ2Kが連続ガードでなくなる隙に、キャラクター別の無敵技・投げ等を狙う。下の候補表は基本的に1番手キム相手・0～1ゲージの効率重視の候補。全技網羅でも、全行が実証済みという意味でもない。

割り込めない：2Kを立ちガードする

2Kはしゃがみガードできない。割り込み入力を試しても、2Kが連続ガードになる場合を考え、途中で立ちガードの保険を失わないことが重要。方向ごとの具体的な入力はページ末尾に保存。

ディレイなしをガード：反撃を狙う

MOTの対キムの基礎攻略では、通常の三空撃出し切りはガード後キム−6F。ディレイで出すと−2Fまたは±0Fまで改善する場合があるとしている。割り込めなかったという事実だけで、必ず−6Fの状況になったと断定しない。

注意：以下は2006年に作った「確定割り込み集（仮）」の候補表です。原著者は、個々の技について未確認のものが多いと明記しています。「なし」はあらゆる割り込み技が存在しないという証明ではなく、当時の掲載対象で有効と判断した候補がないという意味で読みます。

2024年の本人改訂で更新された点

  • 舞：2006年の0ゲージ欄には技の記載がなく、2024年にムササビの舞を追加。舞から見て前方側の壁へ飛ぶ場合は、キムの最速強鳳凰脚に対してもガードが間に合うという本人記述。後方側の壁へ飛ぶ場合にはリスクがありそうだと留保。これは回避・防御を含む対処であり、「ムササビの舞が確定ヒットする」とは書かれていない。
  • ジョー：弱タイガーキックは強版よりダメージが高いとの説明を追加。
  • 立ちガードの保険：もともと2006年の末尾に入力例があるが、2024年版では冒頭から重要性を明記している。

ロバートの強龍牙について：候補表の留保を解決済みにしない

2006年も2024年も、ロバートの0ゲージ欄は「強龍牙が使えそうだが確信が持てない」というMOTの留保のまま。後年、強龍牙は出始め1Fだけ直前の判定を引き継ぐことが本人により確認されている。立ちCDを空キャンセルすると、その食らい判定が残る。立ちガード状態から使うと、そのガード判定が残ってディレイ2Kをガードしてしまう可能性があるが、この連係における割り込みの成立・不成立は別途未確認。詳しくは新旧研究と強龍牙の関連整理を参照。

割り込み以外の逃げ方・キム側のミスへの対応

  • 先行入力の前方大ジャンプ：2007年の本人研究では、ディレイ2Kを立ちガードした後に近Cを空振りさせられるキャラがあり、最悪でも空中食らいになる状況を報告。ただしキムの弱飛燕斬等の対応は別。キャラ差・起き上がり位置・ガード硬直を含め先行入力大ジャンプの別記事で確認する。
  • 追加2Kの入力ミス：追加が出なかったり早く出てしまった場合への反撃は、9K→ディレイ2Kの隙への確定割り込みとは別の状況。相手のミスを前提にした追撃を、毎回の確定反撃と混同しない。

割り込み技を仕込みつつ立ちガードを維持する入力

キムの三連撃～9K～ディレイ2Kは、追加2Kが連続ガードになる場合もある。ディレイ2Kはしゃがみガード不可なので、無敵技などを仕込みながら、技が出ない場合も立ちガードできるようにするのがMOTの対策の基本となる。

方向の読み方

技のコマンドはテンキー表記を主表示にし、その下に方向記号を添えた。テンキー表記は対戦経験者が正確に再現しやすく、方向記号は初めて見る人が直感的に理解しやすいため、両方を併記する。

Nはニュートラル（レバーを離す）。「＋ボタン」は最後に該当ボタンを押すこと。いずれもキャラクターが右向きの場合で、左向きでは左右が反転する。

7↖8↑9↗4←5N6→1↙2↓3↘

コマンド別の入力早見表

表はMOTの原稿にある12種類の入力例を、コマンドの種類・推奨入力・注意点に整理したもの。入力が常に成功するという保証ではない。「謎」「難しめ」「問題なし」などの評価は当時の本人記録に従う。

技のコマンド9Kガード後の推奨入力注意点
236↓↘→9Kを立ちガード → N → 236＋ボタン一度ニュートラルに戻してから入力する。
236236↓↘→↓↘→9Kを立ちガード → N → 236236＋ボタン本人評価：難しめ。
214↓↙←9Kをガード → 214＋ボタン本人評価：問題なし。
214214↓↙←↓↙←9Kをガード → 214214＋ボタン本人評価：問題なし。
623→↓↘方法A：9Kを立ちガード → 623＋ボタン方法B：9Kをガード → 632146＋ボタン方法Aでは、6123という入力にならないよう注意。方法Bは元原稿にある別入力。
421←↓↙9Kをガード → 4214＋ボタン←↓↙←421で止めるとしゃがんだままになるため、4まで入れる。
41236←↙↓↘→9Kを立ちガード → 2146＋ボタン↓↙←→本人は2146で入力する必要があると考えた一方、41236でもしゃがまずに済む現象を記録。理由は「謎」としており、解決済みとは扱わない。
632146→↘↓↙←→9Kをガード → 632146＋ボタン本人評価：問題なし。
2タメ8↓溜め→↑立ちガード保持を優先する推奨入力：1タメ → 4を経由 → 7＋ボタン↙タメ → ←（立ちガードへ移行）→ ↖＋ボタン9Kを1方向でしゃがみガードした後、ガード硬直が解けるタイミングで4を通り7へ。4を経由し、立ちガード状態を作るのが必須。原文（2006年）は「1タメ→4→7or8or9」と記載。8・9も当時挙げた入力候補だが、現在は7を推奨。立ち／しゃがみガードとタメ技の入力使い分けを参照。
2141236↓↙←↙↓↘→9Kをガード → 2142146＋ボタン↓↙←↓↙←→原文では21426でも出ることを利用すると説明。
2363214↓↘→↘↓↙←9Kをしゃがみガード → 2363214＋ボタン本人は、しゃがみガードからの方が入力しやすいはずと評価。

補足：立ちガードを維持する考え方は全入力に一律に当てはめるものではなく、原文にはしゃがみガードから始める2タメ8系・2363214系も含まれる。表では例外をそのまま残した。
