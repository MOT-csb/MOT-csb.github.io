KOF’98｜大門五郎

確定地雷震レシピ

相手キャラを選び、地雷バグのレシピを確認。

38キャラ分の旧レシピを、検索できる形へ再構成しました。

づねさんが整理した既存レシピを基礎に、MOTが発見した「ダッシュ予備動作3F」を利用する調整・レシピなどを加えた統合版です。長年の資料なので、掲載＝現行環境で全件再検証済みではありません。大会投入前は同じキャラ・位置・ゲージ状態で確認してください。

既存レシピを継承MOT独自追加を統合全件再検証前

レシピ検索

使う前に知っておきたいこと

33Fは入れ替え可能

通常前転・通常後転、弱超受け身、小ジャンプ下降中の攻撃は、いずれも合計33Fになる組み合わせがあり、同じ調整として置き換えられます。

最短ダッシュは16F

大門は予備3F＋最低走行10F＋停止3F。最短で止めれば16F調整として使えます。

ジャンプ攻撃の補正

ジャンプ攻撃を出すと滞空が増えます。昇りで出すと2F、着地直前なら1Fを足す調整として扱える、という旧メモがあります。

入力猶予の違い

MAX発動・前転後転・地上CDは4Fほど猶予を取れる一方、通常技・必殺技は同じ感覚で遅らせられないため、レシピの操作難度が違います。

MOT式・フレーム消費パーツ

ダッシュ予備動作は3Fでキャンセルできるため、既存の消費行動に3Fを加えた新しい調整を作れます。

ダッシュ予備 3F＋立CD空キャン 16F＝ 19F

したがって「ダッシュ予備 → 立CD空キャン → 弱地雷震」は19F消費です。これは単独の完成レシピというより、必要な空白時間に合わせてレシピを組み立てるための基本パーツです。

19Fの実用例：対リョウ

従来レシピの「近C投げ → 遠B → 弱地雷震」は、遠Bが19F消費です。これを同じ19Fの「ダッシュ予備3F → 立CD空キャン16F」に置き換えた、次のレシピをMOTが2015年に確認しています。

近C投げ → ダッシュ予備 → 立CD空キャン弱地雷震

MOTの確認投稿（2015/9/1）

空欄のフレームには、元メモ上で対応パーツが未登録です。同じ消費Fでも移動距離や間合いが変わるため、自動的に全キャラで成立するとは限りません。表記は2021年のMOT「確定地雷震レシピ用メモ」を検索用に整えています。

検算：記事内の基本値から単純加算できる複合項目41件は、記載フレームと全件一致しました。前方大Jは、ダッシュ予備3F＋ジャンプ予備4F＋滞空36F＋着地1F＝44F。下降中攻撃は＋1Fで45F、上昇中～頂点側の攻撃は＋2Fで46Fとなるため、元記事で両方45Fに置かれていた後者を、このページでは46Fへ修正しています。

近年の追加確認

大門への追加レシピ

  • 天地返し → 最短ダッシュ → ノーマルジャンプ → 弱地雷震
  • 天地返し → ノーマルジャンプ → 地上ふっとばし空キャンセル弱地雷震

地震判定を仕込む直接連続技

屈D → 地獄極楽落とし入力 → 弱地雷震、および立CD → 地獄極楽落とし入力 → 弱地雷震（対ルガール）は、2023年にMOTが確認した別系統の使い方です。起き上がりへ時間を合わせる標準レシピとは分けて扱います。

回避手段も増えている

出せない超投げ、打撃投げ、一部の屈状態技などで回避できる場合があります。距離を離すレシピを選ぶ意味が以前より大きくなっています。
