DEATH TOWER / FORM GUIDE

デスタワー1〜5式の形と使い分け

「どの形が一番強いか」ではなく、配ぷよと盤面に応じて、組みやすい形を選べるようにするための比較ページです。

MOTの研究では、初心者はまず1式と3式を安定させるのが出発点です。2式・4式・5式は、その形でしか拾いにくい配ぷよや、別の形では制約が増える場面を補う選択肢として整理できます。

結論：形式名を暗記することよりも、起爆部分の効率、連結を伸ばせる場所、潰しへの弱さ、ネクストから無理なく完成できるかを見ることが重要です。

これは絶対的な優劣表ではありません。同じ配ぷよでも、ネクスト、向き、潰しへの備え、多連鎖移行を考慮すると選択が変わります。

FORM 1 / BASIC

1式――まず身につけたい基本形

1式は3式と並ぶ習得優先形です。単に完成形へ向かうのではなく、5列目のぷよをタテ2連結にする意識が、その後の組みやすさを大きく変えます。

研究上のポイント
「両方の色を使えた」だけで満足すると3連結で止まりやすい。タテ2連結、棚上げ、はさみうちまで意識して、連結数を伸ばします。

強み

  • 基本形として反復しやすい
  • 棚上げなどの共通技術を学びやすい
  • タテ2連結から柔軟性を作れる

注意点

  • 右下で必要色が競合しやすい
  • 3連結で止めない
  • 盤面によって3式へ切り替える

出典：MOT投稿（2016年2月25日）

FORM 2 / BRANCH

2式――配ぷよ次第で価値が変わる形

2式は常に狙う形ではなく、ネクストのゾロなどを活かすための分岐として機能します。2式なら苦しいが5式なら組みやすい場合も、その逆もあります。

研究上のポイント
2式を「弱い形」と固定せず、別形式では処理しにくい配ぷよを拾うために使います。ただし、得点と潰し耐性を落とす交換条件を把握して選びます。

強み

  • 特定の配ぷよを素直に活かせる
  • 対応発火を構えれば弱点を補える
  • 5式との使い分けが可能

注意点

  • はなれを作れない
  • 最下部の連結を作りにくい
  • 潰し耐性が下がりやすい

出典：MOT投稿（2016年2月20日）／2式と5式の使い分け（2018年6月17日）

FORM 3 / BASIC

3式（参式）――起爆効率と連結の伸ばしやすさ

3式は、起爆部分に使うぷよを少なくしながら、L字によって連結を伸ばしやすい形です。1式とともに最初に安定させたい基本形です。

研究上のポイント
起爆部分を小さく作れることは、その分だけ他のぷよを2連鎖目の連結へ回せるという意味です。形の完成だけでなく、使ったぷよ数まで見ます。

強み

  • 起爆部分が3個で済む
  • L字から連結を伸ばしやすい
  • 3連鎖移行も検討できる

注意点

  • 特定の序盤形では5式が優る
  • 形を決め打ちしすぎない
  • 多連鎖移行との比較が必要

出典：MOT投稿（2016年1月28日）／デスタワー最適化計画その6

FORM 4 / ADVANCED

4式――制約を読み、あえてゴミぷよを使う

4式では、段差や色の競合によって置き場所が限定される場合があります。一方で、あえてゴミぷよを挟むことで、上部にある複数色を両方活かせることがあります。

研究上のポイント
直接連結できないぷよを排除するのではなく、盤面の高さと接続を調整する中間部品として利用します。赤など必要色を待ちすぎる場合は、3〜4連鎖への移行も視野に入れます。

出典：MOT投稿（2023年8月21日）／多連鎖移行の意識（2021年3月22日）

FORM 5 / ADVANCED

5式――「死んだ場所」を作らない

5式は2式と同様、配ぷよによっては他形式より自然に組めます。ただし、L字とタテ2連結の位置関係を誤ると、3列目に後から利用できない場所を作ります。

研究上のポイント
目の前のタテ2連結だけで判断せず、その下と横に「後からつなげられない空間」が生じないかを確認します。2式との比較では、同じ配ぷよでも組みやすさが逆転することがあります。

出典：MOT投稿（2016年10月8日）／2式と5式の使い分け（2018年6月17日）

実戦での選び方

  1. まず1式・3式を候補にする。基本形としての判断基準を作ります。
  2. ネクストで必要色が競合するなら2式・5式を検討する。ただし潰し耐性と連結数を確認します。
  3. 段差や不要色を処理しながら上部の色を活かすなら4式を検討する。
  4. 形が苦しくなったら形式の完成に固執しない。別発火、3連鎖・4連鎖、ミルフィーユ型への移行を比較します。
