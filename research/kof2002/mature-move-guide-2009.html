KOF2002（無印）｜キャラクター研究

マチュアの技性能：通常技・ジャンプ攻撃・移動・投げ・必殺技・超必殺技の使い方

マチュアの主力は射程無制限の飛び道具エボニーティアーズで、弱の方が弾が遅く発射後の隙も短いので、弱を中心に使います。近Aと遠Aはテリー程度の屈みにすら当たらず、遠Bの2段目はヒット効果が特殊で、Q発動からの超必殺技につなげられます。ここでは2009年5月に7回に分けて書いた技性能解析から、マチュアの全技の性質と使い方をまとめます。立ち回りや対戦相手別の話はマチュアの立ち回りと対マチュアのページにあります。KOF2002UMは扱いません。

記号と用語

  • ＞：キャンセルなしでつなぐ ／ ≫：キャンセルしてつなぐ ／ ～：追加入力・続けて行動する
  • 技名の後の（ ）は、原文に書かれたフレーム数です。攻撃技は「攻撃判定が出るまで, 攻撃判定の持続, 攻撃判定が消えてからの硬直」の順で、2段技は「1段目まで, 持続, 間, 持続, 硬直」のように続きます。[暗転]は暗転の時間、{ }[全身M]はその間全身無敵であることを表します。移動などの数値は原文の表記のまま載せます。
  • デスペアー：軽く飛び上がって攻撃する必殺技。サクラリッジ：多段の必殺技。デスロウ：派生を3つまで出せる必殺技。メタルマサカー：突進技。エボニーティアーズ（エボニー）：飛び道具。ディーサイド：腕を伸ばしてつかむ技。ノクターナルライツ・ヘブンズゲイト：超必殺技。ECSTASY 816：MAX2。
  • GCC+D：ガードキャンセル吹き飛ばし攻撃。Q発動：クイック発動。認識間合い：近距離版の技が出る間合い。

各技の硬直差はマチュアの各技の硬直差、連続技はマチュア連続技にあります。

地上通常技・立ちC+D

技（フレーム）性質と使い方
近A（2, 3, 9）発生が早く、キャンセルがかかります。ただしテリー程度の屈みガードの高さの相手にも空振りするので、固めには向きません。隙が少なく跳び始めの相手にも当たるので、C投げやD投げを狙うときにAを同時押しして暴発させる技として優秀です。連打できるので、相手の前転を見てから連続技で返す始動技としても優秀で、同じ用途の屈みAより発生で勝ります。
近B（3, 3, 8, 3, 11）1段目が下段の2段技。ヒット時は連続ヒットしますが、ガード時は連続ガードにならないので割り込まれる危険があります。ガードされると4F不利なので、密着でガードさせると発生の早い技や1Fコマンド投げで反撃される恐れがあります。認識間合いが狭いのでジャンプ攻撃からは出しにくく、小中JBを意識させて中Jから何も出さずに着地で出すと、展開が早くヒットさせやすくなります。
近C（2, 3+4, 22）発生が早く、認識間合いも近Bより広いので、ジャンプ攻撃からつなぐのに向いています。見た目に反して上方向に攻撃判定がないので、ジャンプされると空振りしやすいのが難点です。
近D（8, 3, 15, 3, 18）2段技でキャンセルできるので、ヒット確認しやすいのが利点です。発生が遅いので、重ねや確定時以外は使いにくい技です。強攻撃の2段技なのでゲージがたまりやすく、相手がガードしていそうなときは、これをガードさせてキャンセル必殺技などでゲージをためるのもよいとしています。補足：1段目を起き上がる相手に重ねると通常投げで返されないので、重ねに自信があれば狙ってもよい、と翌々日に追記しています。
遠A（3, 3, 9）近Aと同じく、テリー程度の屈みに当たりません。動作が短く攻撃判定の位置が高いので、ジャンプ防止技として使います。
遠B（5, 2, 9, 3, 22）2段技。2段目のリーチは長いものの、上方向に攻撃判定がないので牽制技としては使いにくい技です。2段目のヒット効果が特殊で、有利な時間が長いのに離れる距離が短いので、Q発動を絡めるとヒット確認から超必殺技につなぐ連続技ができます。1段目の先端が当たる距離での発生勝負や反撃、屈み弱攻撃から連打キャンセルでつないでヒット確認してQ発動からの連続技、が主な使い方です。
遠C（8, 5, 22）屈まれてもチンとチョイ以外にはガードさせられるので、先端を当てるように牽制で出すと有効です。強攻撃なので空振り時の隙が目立ち、多用は禁物です。
遠D（15, 3, 29）発生は遅いものの、足先の攻撃判定が強いので先端を当てるようにします。動作が長いので多用は禁物です。ガークラ値が高めなのでガードさせたいところですが、不利な時間が長く攻めが続きにくいのが難点です。発動状態なら、どこでもキャンセルでメタルマサカーやエボニーティアーズにつないで連係にできるので、使う価値があるかもしれない、としています。
屈みA（4, 3, 9）連打がきくので、近距離でとりあえず何か出したいときに有効です。ヒット確認して強デスロウや弱ノクターナルライツが連続技になります。遠距離からエボニーティアーズをダッシュで追いかけた場合、相手の前転を潰すのに向いています。
屈みB（5, 3, 8）連打キャンセルできます。屈みAにつないでヒット確認する連続技の始動技として優秀です。同じ下段の近Bより発生が遅いので、ジャンプから何も出さず着地で出してもガードされやすいものの、ガードされてもリスクが少ないので使い分けが大事です。相手の前転に反応して出しても当たらないので、その場合は近Aか屈みAを使います。相手のジャンプをダッシュでくぐった後や、早出しジャンプ攻撃の着地の隙に使えば確定させられます。
屈みC（4, 2+3, 22）斜め上への判定が強く、飛び込みを見てから出す対空技として有効です。対空ではエボニーティアーズ弱強でキャンセルしておくと、相手の着地にうまく重ねにいけます。弱は相手が着地した瞬間に目の前に弾があるので有利を稼ぎやすく、強は着地した相手に重なりやすいので動きを制限しやすい、という違いがあります。密着でガードさせれば一部の相手のGCC+Dを空振りさせられるので、D投げなどを匂わせて狙います。ただしガードされると9F不利で、GCC+Dされずに我慢されると反撃される恐れがあります。
屈みD（8, 5, 25）リーチの長い下段技で、ヒット時はダウンを奪えます。攻撃判定が地面すれすれにしかないので、ジャンプされると当たりません。キャンセルできるので、エボニーティアーズやメタルマサカーでキャンセルします。少しだけディレイキャンセルもできます。
立ちC+D（15, 5, 20）リーチが長く、ヒット時はダウンを奪えます。キャンセルできます。発生は遅いものの先端の判定が強いので、先端を当ててキャンセル弱エボニーティアーズを出していくのが有効です。

ジャンプ攻撃・ジャンプC+D

技性質と使い方
JAリーチは短いものの持続がそこそこあるので、立っている相手にとりあえずジャンプ攻撃をガードさせたいときに使います。
JB2段技。小中Jから出す場合は、ジャンプの頂点の少し前くらいで出せば2段とも連続ヒットさせられます。ガードさせるだけならそれより早く出してもかまいません。ある程度横に食らい判定のあるキャラが立ちガードしているところへ中JからJBを出すと、1段目でめくった後に2段目もヒットさせやすくなります（屈んでいると空振り）。1段目と2段目は連続ガードになっていないので、無敵技などで割り込まれる恐れが一応あります。ノーマル・大Jから出す場合は、下降中に出せば2段とも連続ヒットさせつつ連続技につなぎやすくなります。補足：ノーマル・大JBの場合は連続ガードになり、2段目のリーチが長いので中J・大Jから2段目だけを当てる使い方もある、と追記しています。
JC発生が早く、横方向に攻撃判定が出ているので、空対空の主力です。遠距離でエボニーティアーズを飛び越されたら前方大JC、距離がやや近ければ垂直ノーマルJCや後方JCと使い分けます（すべて昇りで出す）。お互い中ジャンプでの空対空でも威力を発揮し、この場合は主に垂直小JCか後方小JCで出します。地上の相手に狙うには打点を下げる必要があり、屈まれると庵以下の食らい判定の高さのキャラには空振りするので、連続技が決まる状況以外では使わない方がよい、としています。
JD斜め上に攻撃判定が出ているので空対空に使えます。ただし基本は各種ジャンプを使い分けたJCで十分なので、JDはJCでは届かない高さのジャンプ攻撃を空対空で返す場合に限られます。地上の相手には打点を限界まで下げてもテリー以下のキャラに空振りするので、基本的には使えません。
JC+D斜め下にリーチの長い攻撃判定があり、地上の相手に使うと有効です。発生が遅いので、空対空を挑まれると負けます。小中Jから出すと屈まれても安定してガードさせられ、大幅に有利になるので、再び小中J攻撃をしかけるなど主導権を握れます。大Jから出すと、昇り気味でも立っている相手にはヒットかガードさせられますが、屈まれると空振りします。

移動・起き上がり・GCC+D

項目（原文の数値）性質
ジャンプ（5, 34 / 25）滞空時間と高さは平均的で、距離はやや長め。小・中ジャンプとも立っている相手を飛び越えられます。主にJB、JC、JC+Dを使い、各種ジャンプを使い分けられると強い、としています。
ダッシュ（3, 3）ダッシュ中はやや食らい判定が低くなります。
バックステップ（3, 18, 4）標準的。ただ、下がりたいなら攻撃しながら下がれる後方小中Jや、無敵のある後転の方が実用的です。
仰向け起き上がり（21）標準よりほんの少し早い。
うつ伏せ起き上がり（25）標準的。
受け身（24）標準的。チョイの鳳凰脚を食らって受け身を取っても五分なので何も確定しませんが、クーラの強クロウバイツを食らった後は位置を問わず弱ノクターナルライツで反撃できるなど、そこそこ恵まれています。
緊急回避前転・後転・クイック緊急回避とも標準的。
MAX発動標準よりほんの少し動作が短い。投げられ判定があるので、移動投げの回避には使えません。
GCC+D発生は最速クラス。攻撃判定の発生と同時に全身無敵が切れるので、相打ちになることがあるのが難点です。攻撃判定が大きく、地上の相手に空振りする心配はまずありません。

通常投げ

  • C投げ：相手を前方に投げ飛ばし、相手は受け身を取れます。投げ外しの猶予が極端に長く、見てから簡単に外せるので、崩しとしては使えないと言ってよい投げです。相手が前転してきたとき、位置を入れ替えたくない場合に使います。
  • D投げ：相手を後方に引き倒し、受け身不能で背向けの起き上がりにします。投げ外しの猶予が短く、見てから外せないので崩しとして使えます。背向けの強制ダウンを奪えるので、起き上がりに再び崩しを狙えます。D投げ失敗時に暴発するのは近Dですが、空振りの隙が長くて厄介なので、AD同時押しで立ちAに、BD同時押しで立ちBにした方がよい、としています。

必殺技

技（フレーム）性質と使い方
デスペアー軽く飛び上がりながら攻撃します。基本的に強攻撃キャンセルでも連続技にならず、屈まれると大門程度の食らい判定の高さ以外には空振りします。弱は着地の隙が短いので、スタート間合いより少し離れた距離で空中ヒットを期待して使えなくもありませんが、垂直小JCなどの方がリスクが少なく、積極的に使う必要はない、としています。同じくダウンを奪えるサクラリッジと比べると、ヒット後に端同士まで大きく離れます。起き攻めはしにくいものの、積極的に攻める気がなければ遠めで弱エボニーティアーズを出せるので、ペースをつかみやすい利点もあります。
サクラリッジ弱攻撃キャンセルからでも連続技になります。ガードされると隙が大きく確実に反撃されるので、連続技専用と言ってよい技です。弱はもともと強より最大ヒット数が少なく、通常技キャンセルで当てると距離が離れてさらにヒット数が減るので、強だけを使います。同じくダウンを奪えるデスロウと比べ、ヒット後に距離が離れにくいので起き攻めを狙いやすい、という利点に気づけたのがよかった、と書いています。
デスロウ弱攻撃キャンセルで連続技になります。強の方が遠くでヒットしても最後まで連続ヒットしやすいので、強だけを使えば十分です。3つめの派生までヒットさせればダウンを奪えるので、ゲージがないときの連続技の締めに使えます。ガードされていた場合、2つめの派生までは安定して届きますが、3つめは空振りします。派生を出さないか2つめで止めると距離が大きく離れるので、不利ではあるものの反撃されない相手もいます。相手にゲージがなければ削り技として使ってもよい、としています。
メタルマサカー（B：3+0～4+11, 1, 0, 1, 0, 1, 23／D：3+0～8+12, 1, 0, 1, 0, 1, 25）突進技で、ヒットしてもダウンは奪えません。強の方がダメージは少し高いものの、不利な時間も少し長いので、少しでもダメージがほしいとき以外は弱だけでよいとしています。ヒットかガードさせたときのゲージ増加量が多いので、ガードさせる回数が多いほどゲージをためやすくなります。ジャンプされていると一方的に負けるので、突進技として使うなら相手が地上にいそうなときです。具体的には、エボニーティアーズを警戒して前進やダッシュで近づこうとする相手に合わせます。通常技キャンセルで使う場合はガードされてもまず反撃を受けないので、決め打ちで出せばヒット時は連続技、ガード時も少しの削りとゲージためになります。
エボニーティアーズ（A：26, 25／C：26, 27）射程無制限の飛び道具。攻撃判定が上下に大きく、小中ジャンプではほとんどのキャラに飛び越えられません。発生は遅めですが発射後の隙は大きくないので、出せればマチュアのペースにしやすい主力技です。弱は弾速が遅く発射後の隙が短いので弱が中心で、強は弾速が速いので遠距離で弱の裏の選択肢として使います。遠距離で出せば相手の行動を制限できるので、相手が大ジャンプしてきたら昇り大JC、ジャンプしてこなかったらダッシュで追いかけ、相手が前転してきたら屈みAか立ちAの連打から連続技、が基本です。ガークラ値もそれなりにあるので、遠距離で相手が飛び越さずにガードしてくれるなら、蓄積した値を計算してガードクラッシュさせ、メタルマサカーやヘブンズゲイトを決めたり、ある程度ためてから攻め込んで打撃でガードクラッシュを狙うことも一応できます。発射後の隙の部分は食らい判定が低くなっているので、高めのジャンプ攻撃やレオナの強Vスラッシャーを空振りさせられるタイミングがあります。
ディーサイド（B：19, 3, 36／D：21, 3, 38）腕を伸ばし、ヒットしたら後方に大きく投げ飛ばします。ヒット時は背面で受け身不能のダウンを奪え、ダメージも大きいのでリターンは大きい技です。ただしバイスの同じ技と比べて発生が遅く、弱でも強攻撃キャンセルから連続技にならず、動作全体が長くて空振りも怖いので、多用はできません。主な使い方は、弱を強攻撃キャンセルから出して暴れ潰し、強を中JC+Dが地上の相手にカウンターヒットしたときの追撃、です。

エボニーティアーズの暴発を防ぐ入力

コマンド入力に失敗したり、画面内にまだエボニーティアーズが残っていたりすると、デスロウが暴発します。暴発したところに攻撃を食らう可能性もあり、そうでなくても無駄な硬直でペースを崩すので、できれば避けたいところです。

  1. 2362364（4入れっぱなし）+AかCと入力します。デスロウのコマンドが入っていないので、エボニーティアーズが画面に残っていても暴発を防げます。
  2. ただしこの入力では、今度はノクターナルライツが暴発する可能性が出てきます。レバーを4に入れてから、4入れっぱなしでAかCを押せば防げます。

補足：2005年7月の記事でも、2362364+AかCと入力すれば、成立しなかった場合にデスロウの暴発をなくせる、特に弱エボニーティアーズで有効で、暴発で出るのが隙の少ない立ちAになるため、と書いています。'98でもできる、としています。

超必殺技とMAX2

技（フレーム）性質と使い方
ノクターナルライツ（A：{1+28[暗転]+3}[全身M]+1, 2, 14, 2, 14, 2, 15, 2, 3+27／C：{1+28[暗転]+3}[全身M]+4, 1, 14, 2, 14, 2, 15, 2, 3+31／MAX：{1+28[暗転]+3}[全身M]+1, 2, 14, 2, 14, 2, 15, 3, 3+27）弱攻撃キャンセルから連続技になります。無敵が短いので割り込みには使わない方がよい技です。GCC+Dをガードした後の反撃に使えます。弱の方が発生が早い。ノーマル版のダメージはヘブンズゲイトより低く、MAX版はヘブンズゲイトより高くなります。MAX版がヒットした後は最後の飛び道具が残っている扱いになり、エボニーティアーズを出せない時間があるので注意が必要です。端付近の相手に決めた場合は飛び道具がすぐ消えるので一瞬待てば出せますが、中央ではかなり待たないと画面から消えません。
ヘブンズゲイト（B：{1+28[暗転]+10}[全身M], 16, 30、ガード時 0, 2, 0, 4, 40／D：{1+28[暗転]+10}[全身M], 24, 33、ガード時 0, 2, 0, 4, 44／MAX：{1+28[暗転]+10}[全身M], 24, 30、ガード時 0, 2, 0, 4, 40）強攻撃キャンセルから連続技になります。発生直前まで全身無敵なので、割り込みや突進技を返すのに使えます。相手のジャンプ攻撃が下に強くなければ対空にも使えますが、相打ちになるとダメージを与えられません。ヒット時は相手を画面端まで押し込めます。
ECSTASY 816（MAX2：8+28[暗転]+6+5, 24, 20）強制キャンセル対応技。強攻撃キャンセルでも連続技にならず、ガードされると反撃が確定するので、基本的には使わない方が無難です。一応、端付近の相手にJC+DかGCC+Dのカウンターヒットから連続技になります（強制キャンセル対応技なので、発動状態ならGCC+Dに直接キャンセルをかけられます）。マチュアのMAX2の性能の悪さに泣いた、NEOWAVEなら発生まで全身無敵が続くので迎撃技として使えないこともないのに、と書いています。

似ているが別の話

  • サクラリッジとデスロウとデスペアー：どれもダウンを奪えますが、ヒット後の距離が違います。サクラリッジは離れにくく起き攻め向き、デスロウは適度に離れ、デスペアーは端同士まで離れます。
  • ノクターナルライツとヘブンズゲイト：ノクターナルライツは発生が早く無敵が短い反撃・連続技向け、ヘブンズゲイトは発生直前まで全身無敵の割り込み向けです。ダメージの大小はノーマル版とMAX版で逆になります。

気になること

  • 遠Dを発動状態でどこでもキャンセルして連係にする使い方は「使っていく価値があるかも」という段階です。
  • 技性能解析はこの7回で終わっており、MAX2以外のMAX超必殺技の個別の使い方などは書かれていません。
