KOF'95：旧「驚異現象」の技術資料・未確認事項と後年研究への索引（2001～2024年）

MOTの旧「KOF'95 驚異現象」（2001年9月12日作成、2002年4月6日更新、2004年9月13日最終更新・発表）を提供ZIPの原HTMLから再読した索引。原資料はネオジオフリーク等も参考にしており、全件が本人独自発見・独立実測ではない。旧ページはそのまま維持し、手順・未確認の表記・後年の研究を混同しない。

ジョー：旧永久連続技の正確な流れ

MOTは爆裂拳フィニッシュの空キャンセル、強から弱への属性変更、強黄金のかかとの強制キャンセルを組み合わせた連続技を掲載。原資料の要所を保って整理すると、屈B → 連打キャンセル近B → 近B×1 → フィニッシュ空キャン → 近D → 強爆裂拳 → 攻撃判定発生前に強フィニッシュ → 弱へ属性変更 → 近D → フィニッシュ空キャン → 遠D → 強制キャンセル強黄金のかかとという構成である。

さらに永久化の例として、近D → 爆裂拳を介して強フィニッシュ→弱化 → 屈C → 爆裂拳を介して強フィニッシュ→弱化 → 繰り返しを提示。原文の方向コマンドは画像に埋め込まれている部分があり、ここでは推定入力を文字列に置き換えない。これは旧資料に示された連係であり、今回全キャラ・全位置の成立を検証した意味ではない。2004年のジョー攻略記事には、フィニッシュ空キャン・気絶連続技を別の文脈で掲載している。

アテナ：SCB強制停止による永久連続ガード

原文は画面端でSCBを相手にガードさせる → ガードした瞬間にABCD同時押しで強制停止 → すぐSCB → 繰り返しとし、永久連続ガードになるがGCは可能と明記する。途中停止そのものは「紅丸の真空片手駒」「アテナのSCB」「チャンの鉄球大回転」を対象に列挙しており、ABCDを最初から同時押しする方法のほかABC保持→D追加でも止められると説明。

一方、2003年の旧メモの「アテナ近C→一瞬SCB→強制停止後の有利フレームを知りたい」という疑問は、ガードさせる場面・測定対象が異なる。旧「驚異現象」で永久連続ガードを説明していたからといって、近C始動の有利Fが解明済みとは扱わない。

チャン：カウンター攻撃キャンセル鉄球大暴走

2001～2004年の旧原稿はカウンター攻撃をキャンセルして鉄球大暴走を出すと、相手が攻撃避けを使ってもすり抜けられないと説明。これは2023年のMOTによる鉄球大暴走への攻撃避け反撃と一見食い違うが、超必殺技の出し方が異なるため直ちに矛盾とはいえない。

後年記録の成立条件は、通常の鉄球大暴走を一度ガード後、次を見て少し前進→攻撃避け→背後から連続技、という手順。旧「カウンター攻撃キャンセル」条件に同じ処理が適用されるかは未照合。2023年の押し合い判定研究も参照。

ハイデルン：旧ストームブリンガーの「前に使った技」説

旧原稿は、何らかの技を使った後にストームブリンガーを出すと初回吸いのダメージがその技に置き換わると記す。自分の技に限らず、例えばチームメイトのΩルガールのギガンティックプレッシャーを空振り→その後何も技を出さないままKO→ハイデルンのストームブリンガーという大ダメージ例を提示。

2024年のMOTによるガード時のストームブリンガー研究は、最後にガードした必殺技等で置換され、通常技ガードでは上書きされない場合を本人が追試したもの。旧原稿は前に出た技による置換、2024年の記事は相手技をガードしたことによる置換という別の観測経路を含む。2024年の本人訂正を踏まえて読み、旧原稿の全説明が検証済みの内部規則だったとは扱わない。

旧資料に残る追加の主題

キングのトラップショットで相手が空中行動不能になる現象、クラークの右端限定弱バルカンパンチ永久、庵の百合折りの多段ヒット、庵vsチンのイタリアステージ開幕攻撃、チンの轟欄炎炮の左右差、チャンの超必殺技フィニッシュの1/16変化、ルガールのギガンティックプレッシャーとゲージ残存等も記載されている。これらは本稿では原文への索引として提示し、今回の新たな成立確認とはしない。

訂正履歴に関する注意

旧原稿の体力0ドット時の底力は、後年の「KOF'94と'95の違い」で取り消し線付きの不可能説に更新されている。見解変更の記録を参照。いずれも検証手順がない部分を補って確定扱いしない。
